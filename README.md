# 阅读缓存转 TXT

把开源阅读 App「阅读」(Legado) 的章节缓存压缩包，在**手机或电脑浏览器里直接转成按章节排序的 txt 小说**。

**单文件、纯离线、无需安装、不上传任何文件**——转换全部在你的设备里完成。

## 在线使用

> **https://24683456.github.io/legado-cache-to-txt/**

手机打开上面这个地址即可，还能「添加到主屏幕」当 App 用。页面不引用任何外部资源，断网也能跑。

## 用法

1. **选择压缩包**：点虚线框选 `.zip`（电脑上也可以直接拖进去）。
   也支持一次选中多个 `.nb` 文件或整个缓存文件夹，会跳过解压直接转换。
2. **选项**（都可留空）
   - 书名 / 作者：留空则从文件夹名自动识别（自动去掉末尾的 16 位 hash）
   - 章节标题清单：可以选文件，也可以**直接把原书目录页复制粘贴进去**；
     导航、字数、日期等杂质会自动过滤，顺序反了也会自动翻正
   - 附目录页：默认不勾（勾了会在开头插目录列表，阅读器会把正文章节再解析一遍）
3. **开始转换** → 完成后可下载：
   - **分章 txt**：主文件，丢进「阅读」就能看
   - **单章 zip**：每个单章一个 txt，打包下载

## 输出格式

```
书名
作者：某某

第1章 坏了，穿越进电脑里了

　　正文第一段……
　　正文第二段……

第2章 我的帅脸不需要捏

（本文件由「阅读」(Legado) 缓存章节整理，共 395 章，约 89.2 万字）
```

- 章节标题**独立成行、顶格无缩进**，符合「阅读」等阅读器的 txt 目录规则
- **开头不放目录列表**，来源与章数说明放**文末**并用括号包裹，不干扰目录识别
- 每段一段一行、段首两个全角空格，输出 UTF-8 with BOM

## 实现要点

- **原生解压**：自己解析 zip 中央目录 + 浏览器原生 `DecompressionStream('deflate-raw')`，
  不依赖任何第三方库，所以能保持单文件、可离线
- **单章打包**：自己实现 zip 写入（store 模式 + CRC32），避免手机上一个个下载几百个文件
- 一个 zip 里有多本书 → 分别输出；超长章节被拆成 `{序号}-1.nb` 的 → 自动拼回同一章
- 8 路并发解压，395 章的缓存约 0.2 秒处理完

## 已知限制

- **无法直接读「阅读」的缓存目录**（Android 11+ 禁止浏览器访问其它 App 的 `Android/data`），
  所以要先把缓存打包成 zip
- 手机浏览器**只能把结果下载到「下载」目录**，不能写回任意位置
- 需要较新的浏览器：Chrome 80+ / Edge 80+ / Safari 16.4+（`DecompressionStream`）

## 部署

Pages 采用**分支部署**：`main` 分支根目录即站点根目录，推送到 `main` 后自动发布。
根目录的 `.nojekyll` 用于跳过 Jekyll 处理。

**想自己部署一份？** 见 [DEPLOY.md](DEPLOY.md) —— 从"直接下载单文件用"到
"Fork 后开 Pages"，再到 Cloudflare Pages / Netlify / 自建服务器都有步骤说明。

想改造成自己的工具也可以：单文件、零依赖、无构建步骤，直接改 `index.html`。
