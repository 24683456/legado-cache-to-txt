# 阅读缓存转 TXT

把开源阅读 App「阅读」(Legado) 的章节缓存压缩包，在**手机或电脑浏览器里直接转成按章节排序的 txt 小说**。


## 在线使用

> **https://24683456.github.io/legado-cache-to-txt/**


## 用法
将阅读软件的缓存目录打包成压缩包上传即可



本工具只做**格式转换**，不提供、不下载、不分发任何小说内容。请仅用于转换你自己有权处理的文件。

## 部署到自己的 GitHub Pages

**Use this template** 或 **Fork** 建一份自己的仓库，再到 Settings → Pages，
Source 选 `Deploy from a branch`、分支 `main`、目录 `/(root)`，等一两分钟即可。
